总体固定为 X ~ N(μ=50, σ²)。每一列是一次独立抽样；列内观察个体，列间比较样本均数。

理论 SE = σ / √n—

SD：一个人离总体均数多远

SD(X) = σ。它对应左图每一列内部橙色点的上下散布，也对应橙色的 μ ± σ 区域。

SE：一个样本均数离总体均数多远

SE(X̄) = SD(X̄₁,…,X̄ₘ) = σ/√n。它对应右图蓝点的上下散布与蓝色 μ ± SE 区域。

建议实验：保持 σ=3，只把 n 从 4 拖到 64。左图橙色点仍然很散，但右图蓝色均数会明显挤向 μ=50。

这里的 “cluster” 只是一次次独立重复抽样的视觉分组，不是带组内相关性的 cluster sampling。
